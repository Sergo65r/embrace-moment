# Embrace the Moment — WordPress

Текущая витрина и редактор персональных журналов Embrace. Страницы сайта редактируются блоками WordPress, исходные макеты журналов — в разделе **Embrace → Редактор журналов**. Изменения покупателей не меняют макеты владельца.

Ветка `main` содержит WordPress-проект. Прежний HTML/JS-сайт сохранён в ветке `backup/static-before-wordpress-20261105` (коммит `4f488fc9fd54a0f3a410a5e6d3fb4973e179fc29`). История Git сохранена.

## Важно для Beget

Это **не статический сайт**. Загрузка репозитория вместо старого `index.html` не установит WordPress. Нужны PHP 8.2+, WordPress 6.6+ и его база данных. Перед переключением рабочего домена разверните новую версию в отдельной директории на тестовом адресе.

Ядро WordPress, пароли, `wp-config.php`, пользовательские фотографии и база данных не публикуются в этом репозитории. Текущее содержимое страниц и сохранённые владельцем макеты хранятся в базе локального WordPress: для точного переноса их нужно мигрировать отдельно. Исходное наполнение в `setup` не является экспортом всех последующих правок.

Подробный порядок: [Развёртывание на Beget](docs/BEGET.md).

## Состав

- `wordpress-theme/embrace` — блочная тема, оформление, шрифты и интерфейс витрины.
- `wordpress-plugin/embrace-tools` — цены, контакты, блоки и исходное наполнение.
- `wordpress-plugin/embrace-journal` — редактор журналов А4, макеты, локальные черновики, JPEG для владельца, контрольный PDF покупателя, зона пружины и компактные мобильные инструменты.
- `scripts` — проверки и сборка установочных архивов.

## Архивы для установки

Из корня репозитория выполните:

```sh
python scripts/package-wordpress.py
```

В `dist/` появятся:

- `embrace-theme.zip` — **Внешний вид → Темы → Добавить → Загрузить тему**;
- `embrace-tools.zip` и `embrace-journal.zip` — **Плагины → Добавить → Загрузить плагин**;
- `embrace-wp-content.zip` — комплект с директорией `wp-content` для ручного размещения поверх установленного WordPress. Он не содержит базу, конфигурацию и ядро.

## Проверка редактора

Node.js нужен только для локальных проверок, не для работы сайта:

```sh
node scripts/test-resize.cjs
node scripts/test-text-fit.cjs
node scripts/test-binding.cjs
node scripts/test-selection-handles.cjs
node scripts/test-mobile-viewport.cjs
node scripts/test-telegram-touch.cjs
node scripts/test-export-files.cjs
node scripts/test-editor.cjs http://localhost:8881
```

Последняя команда требует запущенный WordPress с активными плагинами и установленными макетами.
Проверка экспортных файлов также использует Python 3 со стандартной библиотекой для независимого чтения ZIP.

## JPEG для владельца

В авторизованном редакторе владельца откройте **Просмотр**, выберите разрешение и страницы, нажмите **Скачать JPEG**:

- 300 ppi: А4, 2480 × 3508 пикселей; основной вариант для телефона и ПК.
- 600 ppi: А4, 4961 × 7016 пикселей; требует больше оперативной памяти.
- Текущая страница скачивается отдельным `.jpg`, весь журнал — ZIP с файлами `page-001.jpg`, `page-002.jpg` и далее в порядке страниц.

Экспорт идёт напрямую из макета, без промежуточного PDF. JPEG создаётся с максимальным параметром качества, ZIP не перекодирует изображения. JPEG остаётся форматом со сжатием с потерями; увеличение разрешения не восстанавливает детали маленьких исходников. Метаданные JPEG содержат выбранную плотность 300/600 dpi. Разметка проколов, рамки выделения и пустые места для фото не сохраняются.

На телефоне ZIP открывается через приложение «Файлы»; после распаковки отдельные JPEG можно сохранить в фотографии. Если автоматическое скачивание заблокировано встроенным браузером, используйте появившуюся ссылку **Готово — скачать** или откройте сайт в обычном браузере. На реальном iPhone скачивание нужно проверить отдельно.

Размер А4 задан без вылетов. Параметры обрезки и переплёта ещё требуют согласования с печатью.

## Повседневная работа

Тексты, изображения и карточки меняются в редакторе страниц WordPress; цены и мессенджеры — в меню Embrace. Не запускайте первичное наполнение поверх отредактированных страниц.

Черновики покупателя сохраняются в его браузере. Для переноса между устройствами предусмотрен файл `.embrace.json`. PDF является контрольным: точные параметры печати и отступы должны быть согласованы отдельно. Зона проколов видна только при редактировании.
