Как установить БЕЗ ручного редактирования кода:

1. Откройте локальную папку проекта embrace-moment.
2. Распакуйте ВСЁ содержимое этого архива прямо в корень embrace-moment.
   Согласитесь на объединение папки assets.
   Существующие картинки товаров не удаляются.
3. Дважды нажмите install_product_images.bat.
4. Дождитесь сообщения "ГОТОВО".
5. Откройте GitHub Desktop.
6. Проверьте изменения:
   - app.js
   - index.html
   - 6 новых .webp в assets/products/
7. Файлы app.js.bak-product-images и index.html.bak-product-images
   НЕ добавляйте в commit.
8. Commit to main -> Push origin.
9. После публикации полностью закройте сайт в Telegram и откройте заново.

Скрипт НЕ меняет редактор, цены, заказы, CSS или другие товары.
Он меняет только 3 соответствия изображений в app.js и добавляет
версию app.js в index.html для сброса кэша.
